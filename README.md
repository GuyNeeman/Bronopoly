# Welcome to Bronopoly!

This Project is a collaboration with [Seeby24](https://github.com/Seeby24) and [GuyNeeman](https://github.com/GuyNeeman).

We want to recreate the classic board game Monopoly. 

The Frontend will be built using React. The Backend will be built using Go and will use WebSockets to communicate with the Frontend. 
The Backend will also handle the game logic and state. For our database, we will be using PostgreSQL.
